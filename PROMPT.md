# Portfolio Development Guide

You are helping build a professional portfolio for Luisa, a Product Designer.

This is NOT a template website.

It is a carefully crafted digital product designed to communicate how she thinks, solves problems and collaborates with multidisciplinary teams.

Every decision should reinforce that message.

# Design Principles

Design should feel:

- Calm
- Professional
- Elegant
- Minimal
- Intentional
- Timeless

Avoid trends.

Avoid decoration without purpose.

Whitespace is a design element.

Content comes before visuals.

---

# UX Principles

Prioritize clarity.

Every section must have a clear purpose.

Reduce cognitive load.

Use meaningful hierarchy.

Guide users naturally through the page.

Accessibility is mandatory.

---

# Accessibility

Always use semantic HTML.

Provide keyboard navigation.

Maintain sufficient color contrast.

Use descriptive labels.

Use correct heading hierarchy.

Never sacrifice accessibility for aesthetics.

---

# Code Principles

Write semantic HTML.

Use clean, maintainable CSS.

Avoid unnecessary nesting.

Prefer reusable components.

Keep JavaScript minimal.

Write code that another developer can understand quickly.

---

# CSS Principles

Use CSS variables.

Use logical spacing.

Prefer Flexbox and Grid.

Avoid magic numbers.

Avoid !important.

Keep naming consistent.

---

# JavaScript Principles

Only add JavaScript when it improves the experience.

Animations should never interfere with usability.

Avoid unnecessary dependencies.

---

# Components

Think in reusable components.

Navigation

Buttons

Cards

Section Titles

Case Study Cards

Badges

Footer

Hero

CTA

Forms

---

# Copywriting

Write concise content.

Avoid buzzwords.

Avoid exaggeration.

Use confident but humble language.

Focus on value instead of self-promotion.

---

# Visual Inspiration

Inspired by:

- Linear
- Vercel
- Notion
- Stripe

Do not copy layouts.

Do not imitate branding.

Only use them as references for simplicity and quality.

---

# What to Avoid

Do not generate generic portfolio templates.

Do not overuse gradients.

Do not add decorative blobs.

Do not use excessive animations.

Do not create unnecessary sections.

Do not use lorem ipsum.

Do not fill space for the sake of filling space.

---

# Expected Quality

Every page should feel like it belongs to a real product.

Every section should have a purpose.

Every component should be reusable.

Every interaction should feel intentional.

The result should communicate professionalism before creativity.
